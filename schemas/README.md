# Schemas

This directory contains versioned machine-readable schemas owned by MNCDS.

Schema identifiers and released schema behavior are compatibility surfaces. Migration MUST preserve existing IDs, required fields, validation behavior, and historical versions unless a reviewed normative change explicitly supersedes them.

MNCS-owned schemas remain in the MNCS repository. If an MNCDS record binds to an MNCS artifact, validate the MNCDS side of that binding here and consume the MNCS artifact through its declared version/interface rather than copying the MNCS schema into this directory.
